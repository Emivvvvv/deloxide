# Security Policy

Security fixes are provided for the latest published release line.

Please do not open a public issue for a vulnerability. Use
[GitHub private vulnerability reporting](https://github.com/Emivvvvv/deloxide/security/advisories/new)
and include the affected version, platform, feature set, impact, and a minimal
reproduction when possible.

Ordinary correctness bugs and documentation issues belong in the public issue
tracker.
